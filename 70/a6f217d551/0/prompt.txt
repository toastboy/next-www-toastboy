State is initialized from alreadyRecorded but won’t update if the prop changes without a remount (e.g., refresh/re-render with updated server data). This can leave the submit button enabled/disabled incorrectly. Consider syncing via an effect on alreadyRecorded (and potentially resetting dirty state) or deriving the value directly from props instead of storing it.

I much prefer the latter

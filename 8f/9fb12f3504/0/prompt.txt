Building URLs via string concatenation can produce malformed URLs if getPublicBaseUrl() ever includes a trailing slash (e.g. https://example.com/ + /footy → https://example.com//footy) or if callers pass paths without a leading slash. Consider normalizing with the URL constructor (e.g. new URL(path || '/', baseUrl).toString()) and/or trimming exactly one trailing slash from baseUrl.

---

The sitemap output isn’t explicitly de-duplicated. While the current inputs may be unique, duplicates can sneak in (e.g. if getAllYears accidentally returns duplicates, or if STATIC_PATHS is edited later), and the spec/test intent is uniqueness. Consider de-duping by URL (e.g. build all entries then filter via a Set) before returning.

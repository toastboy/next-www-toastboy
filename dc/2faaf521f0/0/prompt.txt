The token is interpolated directly into the URL path without encoding. If tokens ever contain reserved characters (e.g., /, ?, #, %), this can break the generated link or allow path/query injection. Encode the token (e.g., encodeURIComponent(token)) before constructing the pathname, and update related tests accordingly.

In Next.js App Router, params is typically a plain object, not a Promise. Typing it as Promise<{ token: string }> can cause confusing/inaccurate types and make it easier to misuse the component. Prefer params: { token: string } and drop the await.

captureUnexpectedError is called for all failures, including expected/handled domain errors (e.g., ValidationError, NotFoundError, ConflictError) that are already mapped to a public message. This can create noisy alerts and hide real incidents. Consider only capturing errors that are truly unexpected (e.g., not your known app error types), or only when the fallback message is used.
